# ラジオサンキュー ウェブサイト改善案

提供された `radio-sanq-website-code.zip` を引き継いだ静的サイトです。既存の6ページ、共通CSS・JavaScript、配色とイラストを活かして改善しています。ビルド・パッケージ導入・サーバー側の送信機能は不要です。本番サイト・ドメイン・DNSの操作は行っていません。

## ローカルで確認する

このREADMEがあるディレクトリで実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

ご自身のブラウザーでポート8000を開いてください。`file://` で開くとPDF確認用のfetchが動かないため、HTTPサーバーを使います。開発環境は既存チェックアウトを使用し、別のworktreeは必要ありません。

## 構成

- `dist/index.html`：地域と局の紹介、聴取・PDF・メッセージ、地域での役割、パーソナリティ、アーカイブ、事業者支援、問い合わせ・SNS
- `dist/personalities.html`：既存原稿の掲載候補。現在の出演者情報との照合が必要
- `dist/archive.html`：ゲスト写真と過去放送を統合した、掲載準備中のページ
- `dist/message.html`：メールアプリに下書きを引き継ぐフォーム
- `dist/business.html`：ラジオCM・番組協賛、SNS、Googleマップ・店舗情報、AI活用の相談
- `dist/about.html`：放送地域、緊急時を含む地域での役割、運営会社、連絡先
- `dist/assets/styles.css`：元のデザインとレスポンシブ・アクセシビリティの改善
- `dist/assets/site.js`：共通ヘッダー・フッター、メニュー、PDF確認、メール起動

## 正式な番組表PDF

承認済みの配布用週間番組表を **`dist/assets/program-guide.pdf`** に追加してください。未配置の間は全ページで「準備中」と表示し、ダウンロードは無効です。

JavaScriptはその相対パスを取得し、成功応答と先頭のPDFシグネチャ（`%PDF-`）を確認してからダウンロードリンクを有効にします。存在しないパスへ200のHTMLを返す静的ホストでも、誤って有効になりません。これは形式の簡易確認であり、内容の正しさや正式な承認を判定する機能ではありません。正式なPDF以外をこの名前で置かないでください。番組データの推測、画面保存PDFの転用、曜日・日時による番組切り替えは行っていません。

PDFを配置した後は各ページを再読み込みしてダウンロードし、内容・配布許可・更新日を確認してください。PDF自体の確認は、実際のファイル提供後に必要です。

## メッセージ

必須は本文のみ。ラジオネームと番組名は任意です。「メールアプリを開く」は `mailto:info@845.fm` に件名・本文を引き継ぐだけで、メールの送信は利用者自身がメールアプリで行います。外部メールアプリの設定によっては開きません。その場合の直接送信先も表示しています。サイトでの入力の保存や送信、アクセス解析の追加はありません。JavaScriptが無効の場合はフォームを非表示にし、直接メールへのリンクを表示します。

ウェブで直接送信する方式への変更には、局が選ぶフォームサービスまたはAPI、承認された送信先、迷惑送信対策、個人情報の利用目的・保存期間・同意文の確定が必要です。サービスや送信先は新たに設定していません。
